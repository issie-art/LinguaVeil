# Idea: LinguaVeil 发展方向评估

## Original Concept
当前项目，可以往哪些方面发展

用户选择方向：功能扩展 + 商业化产品
具体功能：Notion/Obsidian 导出 + LLM 智能翻译增强
资源情况：个人独立开发

## Clarified Understanding

LinguaVeil 是一个 Chrome 扩展，核心功能包括：
- 划词翻译（基于 Google Translate API）
- 生词本管理（带页面标注）
- 知识卡片系统（Side Panel 管理）
- 并行能力开关（translate + flashcard）

用户希望：
1. 扩展导出功能（Notion、Obsidian 等笔记软件）
2. 集成 LLM 提供更智能的翻译/学习体验
3. 最终走向商业化
4. 目前个人独立开发，资源有限

## Target Audience

**当前用户**：
- 工程师/技术人员（阅读英文文档）
- 英语学习者（浏览英文网页）

**扩展后目标用户**：
- 知识工作者（需要整理学习笔记）
- 重度笔记软件用户（Notion/Obsidian 用户）
- 对 AI 辅助学习有需求的人群

## Goals & Objectives

**短期（3-6个月）**：
- 完成 Notion/Obsidian 导出功能
- 集成 LLM API（OpenAI/Claude）提供智能翻译
- 建立付费墙，推出 Pro 版本

**中期（6-12个月）**：
- 达到 1000+ 付费用户
- 支持更多导出目标（Logseq、Roam Research 等）
- 建立用户社区

**长期（1-2年）**：
- 月收入 $5000+
- 考虑全职投入或组建小团队
- 探索 B2B 方向（企业英语学习解决方案）

## Technical Context

- Stack: Chrome Extension (MV3) + React + TypeScript + WXT
- Timeline: 个人兼职，每周 10-20 小时
- Budget: 自筹，可承担 API 费用
- Constraints: 个人开发，需控制复杂度

## Discussion Notes

核心挑战：
1. 个人开发者资源有限，需要聚焦
2. Chrome 扩展市场付费转化率低
3. 需要与现有工具（沉浸式翻译、Language Reactor）差异化
