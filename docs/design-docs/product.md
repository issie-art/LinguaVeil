# LinguaVeil 产品文档

## 产品定位

LinguaVeil 是一款面向英文学习者的 Chrome 浏览器扩展，帮助用户在浏览英文网页时进行即时翻译、生词积累和知识卡片管理。产品名取自 "Lingua"（语言）+ "Veil"（面纱），寓意揭开语言的面纱。

## 目标用户

- 英语学习者（阅读英文技术文档、新闻、博客等）
- 程序员（阅读英文技术资料，区分技术术语与普通词汇）
- 需要快速标记和回顾知识点的学习者

## 核心功能

### 1. 划词翻译（Translate 能力）

**功能描述**：在任意网页上选中英文文本，自动弹出翻译浮窗。

**单词翻译**：
- 选中 3 个及以上字母的纯英文单词
- 显示内容：单词、音标、词性（缩写）、中文释义
- 附加操作：「+ 添加生词」按钮，将单词加入生词本
- 已存在生词本的词显示「已在生词本中」
- 已掌握的词显示「已掌握 · 重新加入生词本？」

**短语/句子翻译**：
- 选中任意非中文文本（上限 1000 字符）
- 显示内容：原文（超过 50 字符截断）、中文翻译
- 无生词相关操作

**限制条件**：
- 不翻译中文文本
- 不响应输入框（textarea、input、contenteditable、CodeMirror 等）内的选择
- 不响应代码区域（code、pre、script 等标签）

### 2. 生词标注（Translate 能力的附属功能）

**功能描述**：自动扫描网页中出现的用户生词本中的单词，添加下划线标注。

**标注规则**：
- 普通词汇（ordinary）：灰色虚线下划线
- 技术词汇（technical）：蓝色实线下划线
- 词汇分类依据预置的 ~300 个技术术语表自动判定

**交互行为**：
- 鼠标悬停标注词 → 弹出释义浮窗 + 「✓ 已掌握」按钮
- 点击「已掌握」→ 移除该词的所有页面标注，标记为已掌握
- 页面动态内容变化时自动重新扫描（1 秒防抖）

**代码保护**：
- 跳过 `<code>`、`<pre>`、`<script>`、`<style>`、`<textarea>`、`<input>`、`<noscript>`、`<svg>` 等标签
- 跳过 `contenteditable="true"` 区域
- 跳过 LaTeX 公式（`$$...$$` 和 `$...$` 格式）

### 3. 知识卡片（Flashcard 能力）

**功能描述**：在网页上选中任意文本，创建知识卡片以便后续回顾。

**创建流程**：
1. 选中文本后，弹出 💡 小方块触发按钮
2. 点击触发按钮 → 展开编辑器
3. 编辑器包含：
   - 正面（front）：自动填充选中文本
   - 背面（back）：用户输入区域，支持 `#标签` 格式添加分类
   - 标签快捷选择：显示最多 10 个已有标签供快速选择
   - 保存 / 取消按钮
4. 保存时自动记录上下文（选中文本前后各 50 字符）和来源 URL

**管理面板**（Side Panel）：
- 通过 Popup 中「打开知识卡片面板」按钮进入
- 功能列表：
  - **添加卡片**：点击「+ 添加」按钮直接创建新卡片
  - 搜索卡片（模糊匹配 front / back / topic）
  - 按标签筛选
  - 展开查看详情（背面内容、上下文、标签、来源链接）
  - 编辑卡片（支持修改 back 和 标签）
  - 删除卡片（二次确认，3 秒超时自动取消）
  - 按创建时间倒序排列
- **标签高亮输入**：背面输入框支持 `#标签` 格式实时高亮（Flomo 风格）
- 实时同步：监听 `chrome.storage.local` 变化，300ms 防抖刷新

### 4. 能力开关系统

**功能描述**：用户可独立控制两个核心能力的开启/关闭。

| 开关 | 默认 | 控制范围 |
|------|------|----------|
| 翻译（translate） | 开启 | 划词翻译 + 生词标注 |
| 标记（flashcard） | 关闭 | 划词创建知识卡片 |

**并行模式**：两个开关可同时开启，此时划词弹窗显示：
- 上半部分：翻译内容（单词含生词操作）
- 分割线
- 下半部分：💡 知识卡片触发按钮
- **原文/译文切换**：创建卡片时，点击右下角「译」/「原」按钮切换正面内容

**开关变更传播链**：Popup UI → Background Service Worker → Content Script（实时生效，无需刷新页面）

## 主题适配

- 自动检测页面深浅色主题
- 检测策略：OS 偏好（`prefers-color-scheme`）+ 页面背景色亮度采样（WCAG 标准）
- Tooltip 和标注下划线根据主题自动切换颜色方案
- Side Panel 独立检测 OS 偏好

## 用户界面入口

| 入口 | 形式 | 功能 |
|------|------|------|
| Popup | 点击扩展图标 | 能力开关 + 打开知识卡片面板 |
| Tooltip | 划词/悬停标注词 | 翻译浮窗 / 生词操作 / 知识卡片创建 |
| Side Panel | Chrome 侧边栏 | 知识卡片管理面板 |

## 数据兼容性

- 支持旧格式（单一 `activeMode` 字段）到新格式（`translate` + `flashcard` 双开关）的自动迁移
- 迁移映射：`learning`/`translation` → translate:true, `flashcard` → flashcard:true, `off` → 全关
